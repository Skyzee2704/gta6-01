SOLMAR 3D — Streets of Gold. A 3D open-world crime game in the spirit of GTA 6, built for make.fun's "Make GTA 6" bounty ($1,666 in USDC, top 100 paid). Explore the sun-soaked coastal city of Solmar on foot and by car — and by helicopter and boat: steal cars, outrun the Solmar Police Department, and run six story missions for Rosa Delgado, from your first getaway to the King of Solmar finale. Three.js 3D, vanilla JavaScript, no network requests. Keyboard + mouse.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
